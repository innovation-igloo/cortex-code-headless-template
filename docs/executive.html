The mission

Agents are going headless

The first wave of AI agents was a chat box. The next wave is embedded: an agent loop running inside your own application, API, or backend service — doing real work without a human watching a terminal.

The Cortex Code Agent SDK gives you that loop, the same one that powers Cortex Code, callable from your code. The open question is where it runs.

Go for launch

A launch-ready template

A headless Cortex Code agent packaged as a real service, with the entire Snowpark Container Services launch sequence already solved and validated end to end.

Clone it, plug in the customer's use case, and deploy — so you spend the POC on the use case, not on “why won't it connect.”

Mission profiles

What you can build with it

The template is an orchestrator. Point the headless loop at a job and it plans, calls tools, and executes — no human watching a terminal.

🔌  Agentic graph engineering

Drive multi-step data engineering across a graph of tables, tasks, and dbt models — the agent plans the work, writes the SQL, and runs it.

📊  Analyst report builder

Wire in Cortex Agents and MCP servers so the loop pulls data, analyzes it, and assembles a finished analytical report end to end.

⏱  Autonomous scheduled ops

Run as a job service on a schedule: nightly data-quality sweeps, backfills, doc generation — headless by design.

🧩  Embedded copilot backend

Drop the endpoint behind your own app or API as the reasoning engine for an in-product assistant.

Pre-flight complete

The hard parts are already solved

Running a headless agent on Snowpark Container Services takes a precise launch sequence. We flew it, tuned it, and baked every step into the template — so your POC starts at “it works.”

Handled in the container

  • The cortex CLI shipped in the image, ready to run
  • Streaming SSE agent loop wired end to end
  • Sessions, permissions, hooks, and custom tools in place

Handled in the deploy

  • The PAT + auth-policy recipe Cortex inference needs
  • External host and streaming egress configured for the runtime
  • Public ingress auth solved and validated
