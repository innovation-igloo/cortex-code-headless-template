Wheels up

Run it locally in two commands

Requires the cortex CLI on your PATH and a Snowflake connection in ~/.snowflake/config.toml.

# install deps and run one prompt against your connection
make sync
make run PROMPT="What tables are in SALES.PUBLIC?"

# or run the API locally
make dev   # then: curl -N localhost:8000/chat -d '{"prompt":"..."}'

dev-first   The same code deploys to SPCS unchanged; only the auth mode differs. See Pre-Flight and Launch.
